# Fonts

- **Titles: NT Brick Sans** (Nurrontype, commercial). Buy a web licence at
  https://www.myfonts.com/collections/nt-brick-sans-font-nurrontype and save the
  web font here as `brick-sans.woff2`, then add this line at the top of `style.css`:
  `@font-face{font-family:"Brick Sans";src:url(/fonts/brick-sans.woff2) format("woff2");font-weight:400 900;font-display:swap}`
  Until then, titles use Pixelify Sans (free, SIL Open Font Licence).
- **Text: Courier Prime** (free, SIL Open Font Licence), a serifed monospace.
